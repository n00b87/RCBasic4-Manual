About RCBasic

RCBasic is a modern dialect of the BASIC programming language designed for creating games and applications quickly while still offering powerful features. It focuses on simplicity, portability, and performance.

With RCBasic v4.12 developers can create desktop games, interactive applications, and multimedia programs with minimal setup. The language is beginner-friendly but powerful enough for advanced projects.

Create 2D and 3D Games

RCBasic includes built-in support for graphics, sound, input, and window management. Developers can easily create both 2D and 3D games using simple commands.

Example Code

Simple example showing a 2D window in RCBasic that renders images and primitive graphics such as Rect, RectFill, Circle, CircleFill, etc.:

OpenWindow("Example", 640, 480, FALSE, FALSE)

paint_canvas = OpenCanvas(640, 480, 0, 0, 640, 480, 1)

Canvas(paint_canvas)

Dim x[3], y[3] 
x[0] = 50 : y[0] = 50 
x[1] = 90 : y[1] = 90 
x[2] = 10 : y[2] = 90 

While Not Key(K_ESCAPE)
  ClearCanvas()
  SetClearColor(RGB(255, 0, 0))

  ' ----- [Draw] -----
  SetColor(RGB(255, 0, 0))
  Rect(100, 100, 32, 32)
  RectFill(200, 200, 32, 32)
  Circle(100, 300, 5)
  CircleFill(200, 300, 5)
  Line(0, 100, 100, 100)
  Triangle(400, 300, 500, 400, 350, 400)
  Poly(3, x, y) 'Draws a triangle
  
    
  ' Update all shape
  Update()
Wend

What’s New in RCBasic v4.12

New features

  • Added UNDO/REDO support to Nirvana2D and Serenity3D.
  • Added full GPU acceleration to all the viewports in Nirvana2D.
  • Added menus to Nirvana2D and Serenity3D with a recent project list.
  • Rearranged the panels in the mesh editor in Serenity3D.
  • Slight speed boost to sprite rendering (noticeable with over 1,000 sprites).

Bug fixes

  • Mouse input is now ignored when Nirvana2D or Serenity3D are inactive.
  • ClearScene() now clears 3D primitives drawn in the scene.
  • Fixed a minor issue in the Triangle() function.
Previous release: v4.11

New features

  • New animation functions were added for tweening between frames in an actor.
  • New physics functions were added to Actor's for setting restitution, contact damping/stiffness, and setting and checking properties for continuous collision detection.
  • OPTION EXPLICIT setting was added to RCBasic Studio. It can also be used from the command line by passing --option-explicit flag to rcbasic_build.
  • A few new examples were added including an example of loading a BSP map and applying some basic FPS controls, a simple 2D platformer project made with Nirvana, and a few others showing of some new features.

Bug fixes

  • Fixed GetSpriteCollision() only returning true when collision first happens. It will now report true as long as the 2 sprites are touching.
  • Fixed TRIMESH shape causing a crash when used with animated actors.
  • Fixed the scheme in Studio not being applied to block comments.
  • Fixed an issue with Triangle() not drawing anything.

Why Use RCBasic?

RCBasic is perfect for beginners learning programming as well as developers who want to prototype games quickly. Its BASIC-style syntax is easy to read and write, allowing you to focus on creating gameplay instead of complicated setup.
