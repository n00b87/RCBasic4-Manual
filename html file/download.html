RCBasic v4.12 fixes a few bugs and makes significant improvements to Nirvana2D and Serenity3D.

Improvements

  • UNDO/REDO support in Nirvana2D and Serenity3D.
  • Full GPU acceleration for all the viewports in Nirvana2D.
  • Menus with a recent project list in Nirvana2D and Serenity3D.
  • Rearranged panels in the Serenity3D mesh editor.
  • Slight speed boost to sprite rendering (noticeable with 1,000+ sprites).

Bug Fixes

  • Mouse input is ignored when Nirvana2D or Serenity3D are inactive.
  • ClearScene() now clears 3D primitives drawn in the scene.
  • Fixed a minor issue in Triangle().
